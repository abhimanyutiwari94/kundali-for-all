# Kundali for All · कुंडली फ़ॉर ऑल

Accurate Vedic astrology and numerology in Hindi and English — kundali with all 16 divisional charts,
detailed predictions with event timing, dashas, yogas and doshas, KP, Lal Kitab, Varshphal, Kundali Milan,
daily/weekly/monthly/yearly horoscopes, Panchang and festivals, and complete numerology.

**Open the app:** https://abhimanyutiwari94.github.io/kundali-for-all/

- **Android:** open the link in Chrome → ⋮ → *Install app*.
- **iPhone / iPad:** open the link in Safari → Share → *Add to Home Screen*.
- **Laptop:** open the link in Chrome or Edge → click the install icon in the address bar,
  or download `Kundali-for-All.html` and double-click it.

The app works offline. Birth details and kundalis stay on your device.
